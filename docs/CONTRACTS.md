# Shared command contract

Authoritative executable types: src/domain/types.ts and src/data/ledger-port.ts. All dates are ISO date-only strings for entered dates, UTC ISO instants for audit. Amounts are safe integer USD cents; other parent's percentage is integer basis points. Amount range 1..100000000; basis points 0..10000. Approved records are frozen permanently in this MVP.

Every financial mutation returns ExpenseDetail {expense, reimbursements, audit}. A corrected draft returns the NEW record. Reimbursement resolution expectedRevision refers to its parent expense.lockVersion. Every mutation increments the expense revision. Idempotent replay uses actor + operation + key and an exact canonical payload fingerprint; compare payload before revision. Receipt attachment uses the same revision and a final locked server check. CreateInvite is the documented exception: invalidate prior unused invitations; store only the hash; never persist its raw token in command results.

Real Supabase transport: ledger_read(p_operation, p_id default null) operations getContext/listChildren/listExpenses/getExpense; ledger_command(p_operation, p_payload jsonb, p_expected_revision nullable, p_idempotency_key) for all commands except createInvite and uploadReceipt; ledger_create_invite(p_email, p_base_url) returns InviteResult. Payload uses the command's camelCase argument names: id,input; expenseId,amountCents,paidOn,methodLabel,note; reportId,decision,note; token; alias. createHousehold payload is {}. Financial actor is ALWAYS auth.uid(). Error code appears in the SQL exception message and maps to LedgerError. RPC outputs use the TypeScript camelCase shapes.

Receipt Edge endpoint receipt-upload accepts multipart {draftId,expectedRevision,idempotencyKey,file} with bearer session; returns ExpenseDetail. Receipt signing uses receipt-access Edge endpoint with {receiptId}, returns ReceiptAccess (TTL <=60s). Private bucket receipts; no client write policy. Upload Edge validates type signatures and size, then invokes receipt finalization RPC which locks the expense. Signed links only after parent visibility authorization.

DemoLedger(storage, actorId='alex') implements LedgerPort. setActor('alex'|'jordan'), reset('clean'|'examples') and attachSampleReceipt(id,meta) are DEMO-ONLY extras. All writes to a dedicated sessionStorage key; neither authentication nor actual files belong here. Clean mode has a joined synthetic two-parent household and Child 1, with zero expenses. Default examples use the exact golden data. No API calls in demo. Export CSV shared helper uses only records the port can read.
